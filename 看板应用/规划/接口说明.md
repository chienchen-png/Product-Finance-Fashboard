# 数据接口与边界

适用：三页看板v3.1.1，2026-10-16验收。程序内置只读HTTP适配；每位用户配置自己的`HT_APIKEY`，无需另装Skill或接入模型服务。认证仅在后端读取。

| 内容 | 主源 / 补充 | 已验证边界 |
|---|---|---|
| 境内证券价格、盘口 | 华泰getQuote；腾讯/新浪回退 | 华泰缺行情时间、量额；补充字段逐项标源，不冒充同一时点 |
| 日线、5分钟K线 | 腾讯；北交所及境内成交额用东方财富补充 | 华泰连续一个月数组未稳定取得，继续使用公开源；无权限/空数据结束等待 |
| 行业、股票/ETF/LOF排行、快讯 | 新浪 | 行业覆盖范围不等于全A；未知源时间保持未知 |
| 市场、海外、资金、事件、行业分析 | 华泰marketInsight | 原文为供应商生成，日期、数字、引用待核验；仅手动更新 |
| 产品关键点与风险 | 华泰diagnosisStock | 境内证券走诊断；已接入指数/汇率/黄金走市场洞察；均在详情内按需查询 |
| 产品主力净流入 | 华泰queryIndicator | 512890、513100、518880通过重复JSON补测；校验代码、日期、金额与单位，失败保留旧文 |
| 技术指标与市场摘要 | 本机计算 | 使用缓存K线、可核验量额与行业数据；样本不足不填造 |

主力资金为供应商定义的成交分类净额，不是已识别的机构账户资金，也不是ETF申赎净额。行业资金多次查询存在口径差异，暂不生成资金热图。报告的链接默认未核验，HTTP200不能证明内容正确。

行情与研究独立缓存、独立刷新。研究并发2项、等待4项，同主题/对象去重30分钟；指标请求最多60秒，市场/诊断最多120秒。失败不改旧文获取时间。网页禁止执行报告HTML，不自动加载远程图片。

配置：Windows用户环境变量`HT_APIKEY`，或用户目录`.htsc-skills/config`中填写`HT_APIKEY=自己的密钥`；重启服务生效。无密钥可用公开补充行情与已有缓存。设置`HTSC_MARKET_MODE=public`可只用补充源。

公开网页源可能缺字段、延迟或不可访问。以上为已测样本能力，不承诺全部产品与历史日期覆盖。程序不读取手机比赛账户、不调用模拟下单或真实交易；账户由用户确认的信息维护。
