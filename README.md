# 比赛看板

本地投资看板：把行情、行业、排行、快讯和投研资料接到一块大屏上，同时维护你自己的模拟账户。Windows 单文件启动，双击即用，网页开在本机 `127.0.0.1`；不连接券商、不读取手机账户、不提交任何买卖指令。

面向“智投未来·全国高校大学生AI金融科技挑战赛”的全国校园模拟赛（虚拟资金 100 万元），也适合任何“想在本地看盘＋记账”的场景。

## 功能

| 页面 | 内容 |
|---|---|
| 市场 | 指数卡、行业热力图、股票/ETF/LOF 排行、量能与覆盖统计、财经快讯；无数据的模块自动隐藏 |
| 投研 | 宏观资料（A股、海外、资金、事件、行业）按需更新，保留原文与取数时间 |
| 账户 | 总资产、收益率、现金、持仓市值、收益曲线、持仓分布；持仓点开含 K线与“产品分析”页签 |

- **K线**：日线、5分钟、前复权切换，十字光标、滚轮缩放、拖动平移、区间滑块；无数据或权限受限时给出原因，不空转。
- **记录/导入**：成交与委托只需四项——方向、代码、数量、价格。交易所按代码判定，名称自动带出，费用按赛事规则自动计，编号按内容去重，时间默认当前北京时间。
- **开账**：首次自动创建 100 万元、零持仓账户；已有持仓用一次手机快照开账，不必补历史买卖。
- **支持品种**：沪深A股、场内基金（ETF/LOF/REITs）、北交所、港股通。港股通按港币成交、人民币入账，折算率自动获取；不支持美股、两融、可转债、期货期权。
- **交易时段**：状态条分列 A股（9:15—11:30、13:00—15:00）与港股通（9:00—12:00、13:00—16:00，不含 16:00—16:10 收市竞价）；联动刷新覆盖两者并集。

## 数据来源

| 数据 | 主源 | 补充／回退 | 已知边界 |
|---|---|---|---|
| 境内证券报价、盘口 | 华泰 Skill（需自备 `HT_APIKEY`） | 腾讯 / 新浪 | 华泰不返回行情时间；量额等字段来自公开源并逐项标注 |
| 港股报价 | 腾讯 | — | 华泰未覆盖港股 |
| 日线、5分钟K线 | 腾讯 | 东方财富（北交所、境内成交额） | 港股只有前复权日线，无分钟线与成交量 |
| 行业、排行、快讯 | 新浪 | — | 源不提供日期时显示“时间待核” |
| 港元/人民币折算率 | 新浪外汇 | 最近一笔港股成交汇率 | 香港假期未核 |
| 市场／海外／资金／事件／行业分析 | 华泰 `marketInsight` | — | 供应商 AI 生成，日期与数字待核验 |
| 产品分析 | 华泰 `diagnosisStock`（境内证券）／`marketInsight`（指数、汇率、黄金） | — | 同上，仅手动更新 |
| 技术指标与市场摘要 | 本机 `源码/指标.py` 计算 | — | 样本不足不填造 |

公开网页接口不是授权行情服务，可能延迟、缺字段或不可访问；程序按实际取到的内容展示，不用猜测值补位。

### 配置自己的密钥

在 Windows“用户环境变量”中设置 `HT_APIKEY`，或写入用户目录 `.htsc-skills/config`（内容 `HT_APIKEY=你的密钥`），完全退出程序后重启。密钥只在本机后端读取，不进入项目、Git 或日志。未配置时仍可使用公开补充行情与已缓存资料。设置 `HTSC_MARKET_MODE=public` 可强制只用公开源。

## 快速开始

1. 克隆或下载整个仓库，不能只下载 EXE（`_internal` 必须与 EXE 同级）。
2. 双击 `比赛看板.exe`，浏览器自动打开 `http://127.0.0.1:8765`（被占用时顺延，以实际地址为准）。
3. 首次启动自动同步一次行情；“启动联动”可选每 5 或 20 分钟更新，“更新行情”用于手动刷新。
4. 首次已自动建账为 100 万元、零持仓，尚未交易可直接登记首笔成交。

仅同一台电脑的浏览器能打开该地址，其他设备无法通过 `127.0.0.1` 访问。关闭全部页面约 5 分钟后服务自动退出，下次双击 EXE 即可。

## 第一次怎么初始化

首次自动创建 100 万元、零持仓账户；尚未交易可直接登记首笔成交。

**已有持仓：用一次快照开账，无须补齐历史买卖**（“记录 / 导入”→“手机账户快照”→“填写表单”）：

| 信息 | 填写要求 |
|---|---|
| 汇总 | 手机总资产、现金余额、持仓总市值；有港股持仓时填港币折算率（人民币/港币） |
| 持仓 | 每只产品代码、数量、持仓均价、手机现价；港股均价按港币填 |
| 时间 | 上述手机数据对应的北京时间 |
| 选填 | 今日盈亏、持仓盈亏、可卖数量，未知留空 |

交易所自动识别、名称联网补全。总资产须等于现金＋持仓市值；有委托冻结时可用资金不等于现金，无法确认就先撤单再对账。预览无误后确认，此后只登记快照时间之后的新成交；收益率始终以 100 万元初始资金为基准。

## 日常使用

- 成交只需四项：**方向、代码、数量、成交价**。交易所按代码自动识别（5 位港股通、6 位沪深北），名称联网补全，编号按内容去重，时间默认当前北京时间（补记旧成交在“更多”里改）。仅挂单不算成交，部分成交只登记实际数量。
- 费用留空按本赛事规则推定：沪深万3、北交所万2.8、港股通0.1257%（净佣金0.013%＋印花税0.1%＋过户费0.0042%＋其他0.0085%）；与手机不一致时可在“更多”里覆盖。这不是实际券商费率。
- 表单、JSON/CSV 都是先预览后提交；开账后再次对账，数量须与基线＋新增成交一致，不能用快照掩盖漏记成交。
- 运行后在程序目录生成 `数据/`，备份它即可迁移账户；更新程序不会动账户。

## 目录结构

```text
比赛看板.exe        程序（双击运行）
_internal/          运行库，必须与 EXE 同级
源码/               服务、账务、页面、指标与数据源适配
  数据源/           华泰、腾讯、新浪、东方财富适配
  图表依赖/         ECharts 及其许可
资源/               交易日历、技能版本清单
测试/               自动化测试（账号只落临时目录）

数据/               首次运行生成，Git 忽略
```

## 从源码运行与自行打包

需要 Python 3.10+（开发与验收使用 3.14）：

```powershell
python -m pip install -r requirements-dev.txt
python -X utf8 源码/启动器.py            # 源码启动，读取同目录 `数据/`
python -X utf8 测试/运行全部测试.py       # 自动化验收
powershell -NoProfile -ExecutionPolicy Bypass -File 构建/构建发布.ps1 -目标 独立
```

打包前请关闭正在运行的程序；构建脚本只更新程序文件，`数据/` 原样保留。浏览器相关测试需要本机 Edge，个别构建测试需要 PowerShell 7。

## 常见问题

| 现象 | 处理 |
|---|---|
| 页面打不开 | 确认 `比赛看板.exe` 与 `_internal` 同级；查看 `数据/看板服务.log` |
| 端口 8765 被占用 | 程序自动顺延到 8775 内其他端口，以实际打开的地址为准 |
| 某只产品没有 K线 | 该市场无历史接口或权限不足，界面会说明原因；不影响报价与记账 |
| 换电脑 | 复制整个程序目录，并带上 `数据/`（账户与行情缓存都在里面） |
| 只想清空重新开始 | 关闭程序后删除 `数据/账户记录/比赛账户.json`，重启自动建 100 万元新账 |

## 隐私与边界

- 只在本机运行，仅监听 `127.0.0.1`；账户数据不上传、不发送给行情接口。
- 不读取手机模拟账户、不连接真实交易、不自动下单；账户完全按你确认的信息记账。
- 公开行情源与供应商文本均可能滞后或出错，程序标注来源与时间，不构成投资建议。
