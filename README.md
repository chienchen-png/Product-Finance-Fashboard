# 全国校园模拟赛 · 比赛看板（队友版）

本机运行的模拟盘账户与行情看板：记录你的成交、看持仓与盈亏、看行情与板块强弱。
**只做记录与展示，不代下单、不接真实资金、不读取华泰模拟账户。**

---

## 一、运行

1. 解压整个文件夹，`比赛看板.exe` 与 `_internal` 必须在同一层（缺一不可）
2. 双击 `比赛看板.exe`
3. 浏览器自动打开 `http://127.0.0.1:8765`；全部页面关闭约 5 分钟后服务自动退出

不需要安装 Python，不需要任何密钥。首次启动会在同级生成 `数据` 文件夹，那是你自己的账本。

---

## 二、首次使用：把已有账户开账

**已经交易过（推荐用这个）**：点右上「记录 / 导入」→ 类型选「手机账户快照」，填四项总额＋每一只持仓：

- 总资产、可用资金、持仓市值、持仓盈亏
- 每只持仓：代码、交易所、数量、成本价、现价（可卖数量可选填）
- 总资产必须等于持仓市值＋可用资金；有冻结资金时以"可用资金"为准

预览 → 确认记录。这一步建立**期初基线**：收益率从 100 万起算，之后的成交按你确认的逐笔入账。
开账前的历史成交与已实现盈亏不追溯，页面会如实标注。

**完全没交易过**：跳过这步，直接录成交即可。

**想把历史每一笔都补进来**：用「已确认成交」逐笔录（代码、方向、数量、价格、时间），全部录完后再做一次手机快照。
只有把全部成交录全，持仓数量才会与手机一致——系统不会替你造交易。

---

## 三、日常使用

**每笔成交**：记录 / 导入 →「已确认成交」→ 最少只填五项

| 必填 | 说明 |
|---|---|
| 产品代码 | 6 位，如 `510300` |
| 方向 | 买入／卖出 |
| 数量 | 股数 |
| 成交价 | 按手机实际成交价 |
| 成交时间 | 北京时间 |

其余全部自动：交易所按代码前缀判定（5/6 沪、0/1/3 深、4/8/9 北交所），产品名称由接口带出，手续费按赛事规则计算（沪深万3、北交所万2.8，无印花税与过户费），成交编号自动生成且重复导入只算一笔。

价格与时间必须本人填：成交可能发生在盘中任意时刻，也可能是多笔均价，用行情价反推会污染后面所有盈亏与归因。

**每天收盘后**：用「手机账户快照」对一次账。差额会明确列出，不会替你抹平。

**看行情**：市场页自动同步，点开任意产品可看 K 线、均线、MACD、RSI、成交量与成交额。没缓存过的产品首次点开约 10—60 秒补数，之后秒开。

**跟踪候选**：把标的加进「本地自选」，指标会一并计算。

## 四、数据与备份

- 账本：`数据/账户记录/比赛账户.json`；行情缓存与收益曲线同在 `数据` 下
- 备份：直接复制整个 `数据` 文件夹
- 换电脑：整个文件夹拷过去即可
- 不要把文件夹放进会被云盘实时同步的位置（容易产生文件冲突）

---

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击一闪而过 | 多半只复制了 exe 没带 `_internal`，两个必须在同一层 |
| 页面打不开 | 看 `数据/看板服务.log`；端口 8765—8775 被占用会自动顺延，日志里是实际地址 |
| 显示"行情时间待核" | 该接口没给时间戳，不填 0、也不假装实时 |
| 断网 | 页面照常打开，行情显示最后一次成功数据并标注过期 |
| 快照报"持仓数量与已确认成交不同" | 说明还有成交没录全；先补成交，或按第二节用期初基线开账 |
